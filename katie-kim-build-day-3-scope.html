Fathom → Airtable · Company/project linking · Attendee check · Meeting notes · Remove raw transcript
🔴 High Priority ▶
What's already there: Fathom transcript → AI extracts action items → Tasks created in Airtable with Pending Approval status → Katie reviews in Pending Approval interface and assigns to team members → assignee receives email notification. The core pipeline is working. This build upgrades what the automation captures per task.
  • Add company and project linking to task creation
    When the automation creates tasks from meeting transcripts, it should attempt to identify the associated Company and Project from the meeting context (attendees, meeting title, transcript content) and link them automatically. If a confident match exists in Airtable, link it. If no match, leave blank for Katie to fill during Pending Approval review.
    AutomationAI
  • Add pipeline linking to task creation
    Where a task relates to an active pipeline record (e.g. prospect follow-up), link the task to the corresponding Pipeline entry. This closes the loop between meeting activity and pipeline tracking — so tasks from a client meeting appear against that pipeline record.
    AutomationTable
  • Add attendee extraction and Contacts check
    Pull calendar attendees from the meeting. For each attendee, check if they exist in the Contacts table. If they don't exist, create a Pending Approval task for Katie: "Add new contact — [Name] from [Company] — met in [Meeting Title]." No silent additions — everything goes through Katie's approval.
    AutomationAI
  • Add meeting notes generation to automation
    Add an Airtable AI step to the existing meeting automation. Using the Fathom transcript text + attendee list as inputs, the AI generates structured meeting notes based on Katie's template (to be provided). Notes stored as a long text field on the Meeting record. Katie said: "It will take me like two hours to create meeting notes" — this eliminates that entirely.
    AutomationAI
  • Remove raw transcript from automation output
    The full transcript text is currently included in task/meeting records. Remove it — the transcript lives in Fathom; Airtable should only store the structured outputs (action items, meeting notes, attendees). Keeps records clean and the AI Q&A feature in the Meeting Transcripts Dashboard remains the right tool for querying full transcripts.
